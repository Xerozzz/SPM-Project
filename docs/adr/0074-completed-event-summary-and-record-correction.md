# ADR-0074: Separate completed-event summaries and record correction

- **Status:** Proposed
- **Date:** 2026-10-30
- **Related stories:** SCRUM-86, SCRUM-88
- **Extends:** ADR-0071

## Decision

Completed events will use compact summary cards. View details opens the event plan, versioned
closure record, and existing correction form. Returning restores the card list.
This changes no completion, correction, or history rules.
