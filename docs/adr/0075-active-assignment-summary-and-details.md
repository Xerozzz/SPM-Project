# ADR-0075: Separate active-assignment summaries and details

- **Status:** Proposed
- **Date:** 2026-10-30
- **Related stories:** SCRUM-100, SCRUM-97, SCRUM-88
- **Extends:** ADR-0073

## Decision

Active Assignments will use compact cards consistent with the Coordinator review queue. A card
shows status, schedule and venue; View details reveals the existing reassignment and history
controls for one event. API ownership and reassignment checks remain authoritative.
